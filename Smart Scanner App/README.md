This project helps scanning documents by automatic name presets,save location selection, crop photos, etc.
it helps saving multiple people's similar name docs 

This project uses below python modules:
    - pillow
    - pywin32
    - pymupdf

you can see the output of the app by executing the .EXE file present in this folder.


steps to use this app:
1. select the folder where to save your docs or enter the folder name and select the location to create a new folder of that name. (location selection is one time process)
2. now after location selection, select the name preset or if preset not available then you can crete new preset
3. after preset selction select the output format PDF or IMAGE
4. then click on SCAN button :
    - if you want multipage PDF or multiple images then 'Batch scan'
    - if you want single page pdf or image then 'Scan Single'

5.  after scanning you can preview scanned image in right side
